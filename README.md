# Healthcare Doctor Visit Analytics

## Project Overview

Healthcare Doctor Visit Analytics is a Data Analyst Internship project that analyzes patient and healthcare-related data to understand the factors associated with doctor visit frequency.

The project uses Python for data cleaning, exploratory data analysis, statistical analysis, and predictive modeling.

## Objectives

- Understand the structure and characteristics of the healthcare dataset.
- Clean and prepare the data for analysis.
- Analyze doctor visit patterns using exploratory data analysis.
- Study relationships between healthcare factors and doctor visits.
- Apply statistical tests to identify significant relationships.
- Build predictive models to identify frequent doctor visitors.
- Compare different machine learning algorithms.
- Identify the most important features influencing predictions.

## Dataset

The dataset contains 5,190 patient records and healthcare-related attributes such as:

- Doctor visits
- Gender
- Age
- Income
- Illness
- Reduced activity
- Health status
- Insurance information
- Chronic conditions

## Machine Learning Models

The following classification algorithms were compared:

- Logistic Regression
- Decision Tree
- Random Forest

The target variable identifies whether a patient is a frequent doctor visitor based on having two or more recorded doctor visits.

## Evaluation Metrics

The models are evaluated using:

- Accuracy
- Precision
- Recall
- F1 Score
- Confusion Matrix
